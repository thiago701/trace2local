# Scripts de captura da UI v2 (legado)

Estes scripts (`capture*.mjs`, puppeteer-core + Edge no Windows) produziram as
evidências históricas `docs/qa/screenshots/01..22-*.png` da **UI v2** e são
referenciados pelos relatos em `docs/qa/EVIDENCIA-*.md`. Eles dependem de IDs de
DOM que não existem mais na UI v3 (Resonance).

Para a UI atual use o **loop de usabilidade por persona** em
[`scripts/ux-loop`](../ux-loop/) (Playwright, checks automáticos + telas em
`docs/qa/screenshots/v3-ressonancia`).
